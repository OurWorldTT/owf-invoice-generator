# OurWorldFoundation Project

## Invoice Generator

Invoice Generator is the public OurWorldFoundation web application for creating,
previewing, saving, printing, and sharing invoices and receipts. It includes a
responsive web interface and a Capacitor-compatible mobile build.

### Features

- Invoice and receipt creation with automatic document numbering
- Printable and downloadable PDF-ready document layouts
- Light, dark, and system appearance modes
- Client contact presets
- Typed or hand-drawn saved signatures
- Business profile and optional customer-facing business logo
- Searchable document history
- OW Login Portal integration using Authorization Code with PKCE
- Authenticated, user-isolated document and profile storage
- Database-backed request rate limiting and audit events
- Android and iOS packaging through Capacitor

The OurWorldFoundation brand mark is used by the application interface and
favicon only. It is not inserted into generated invoices or receipts.

### Project structure

- `index.html`, `styles.css`, and the root JavaScript files provide the frontend.
- `assets/` contains application branding assets.
- `backend/` contains the Vercel API, authentication, validation, and migrations.
- `database/schema.sql` is the canonical public database schema.
- `mobile/` contains the production web-bundle build script.
- `tests/` and `backend/tests/` contain frontend and API regression tests.
- `dist/` is generated by the production build and is not committed.

### Local setup

Requirements: Node.js 20 or newer and npm or pnpm.

```powershell
npm install
npm test
npm run build
```

Serve `dist/` through a local HTTP server for browser testing.

Backend dependencies and tests are managed separately:

```powershell
cd backend
npm install
npm test
```

### Frontend configuration

Public frontend settings are defined in `config.js`.

- `apiBaseUrl`: deployed public API origin
- `authMode`: use `development` locally or `ow-login` in production
- `loginPortalUrl`: authorization endpoint
- `loginPortalTokenUrl`: token endpoint
- `loginPortalLogoutUrl`: optional logout endpoint
- `loginPortalClientId`: public OAuth client identifier
- `loginPortalRedirectUri`: registered production callback URL
- `loginPortalScope`: requested OIDC scopes
- `paypalDonateUrl`: optional PayPal contribution destination

Never store a client secret, database connection string, or other private
credential in frontend files.

### Backend configuration

Deploy `backend/` as a Vercel project and configure the variables listed in
`backend/.env.example`. The production backend must connect only to the public
`invoice_public` database and accept requests only from approved frontend
origins.

Run `backend/scripts/init-db.mjs` with a direct database connection when setting
up a new environment. Existing installations should apply migrations in numeric
order from `backend/sql/`.

### Mobile packaging

```powershell
npx cap add android
npm run sync:android
npx cap open android
```

iOS packaging requires macOS and Xcode:

```bash
npx cap add ios
npm run sync:ios
npx cap open ios
```

### Ownership

Invoice Generator is an OurWorldFoundation project. The public application and
its database must remain separate from the private OurWorldTT business edition.
